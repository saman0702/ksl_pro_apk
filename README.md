# KSL Pro APK (Katian Pro)

Application mobile Flutter **Katian Pro** (compagnie / transporteur).

## Stack

- Flutter / Dart
- Android + iOS

## Développement

```bash
flutter pub get
flutter run
```

## Build Android

```bash
flutter build apk --release
# ou
flutter build appbundle --release
```

Voir aussi `GUIDE_DEPLOIEMENT_PLAYSTORE.md` si présent.
